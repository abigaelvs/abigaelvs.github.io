Avids.Dapper.Lambda

Open-source NuGet library · 1,800+ downloads

A Dapper extension that adds lambda expressions with an elegant chain style, so queries and commands read like LINQ while staying on top of plain IDbConnection. 

con.QuerySet<SysUser>()
   .Where(a => a.Email == "user@example.com")
   .OrderBy(a => a.CreateDatetime)
   .Select(a => new SysUser { Email = a.Email })
   .PageList(1, 10);
  • Built on Dapper and keeps the original Execute and Query methods available
  • Chained QuerySet and CommandSet APIs with ExpressionBuilder for dynamic filters
  • Full async support (ToListAsync, GetAsync, InsertAsync, UpdateAsync, DeleteAsync)
  • Respects native attributes such as [Table], [Key], and [Column]
  • Published on NuGet under the MIT license, with a sample app and a unit test project in the repository
